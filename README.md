# 🛡️ Siber Koruyucu v5.0 ULTRA - Cybersecurity & AI Defense Center

**Siber Koruyucu v5.0 ULTRA** is a modern, 7-tab desktop cybersecurity and AI-powered anomaly detection application built with Python and Tkinter. Designed to protect users from digital threats, it combines password security, phishing detection, AI scam message analysis, encryption, live network auditing, and IoT sensor protection in a single lightweight tool.

## 🚀 Key Features

- **🔑 Password Shield:** Analyzes password strength, estimates brute-force cracking time, and generates cryptographically strong 16-character passwords.
- **🌐 Phishing Link Radar:** Scans URLs against 6 cybersecurity rules to detect phishing traps, raw IP links, `@` redirection tricks, and suspicious keywords.
- **🕵️ AI Scam SMS & Email Detector:** Uses NLP keyword and social-engineering pattern analysis to calculate scam probability percentages in suspicious messages.
- **🔒 Crypto Vault (Encryption):** Locks sensitive notes or passwords using XOR + Base64 encryption protected by a custom secret PIN.
- **📡 Live Network & Wi-Fi Shield:** Audits the connected Wi-Fi network's encryption protocol (WPA2/WPA3 vs. Open/WEP) and scans for vulnerable open system ports (Ports 21, 23, 445, 3389).
- **❄️ AI IoT Cold-Storage Shield:** Uses statistical anomaly detection (mean & standard deviation analysis) to catch sudden temperature spikes or defrost manipulation cyberattacks on smart refrigeration systems.
- **📋 Automated Security Logs:** Records every scan and blocked threat with timestamps into a local report (`siber_rapor.txt`).

## 🛠️ Technologies Used

- **Language:** Python 3
- **GUI Framework:** Tkinter (`ttk`)
- **Modules:** `re`, `statistics`, `socket`, `subprocess`, `random`, `base64`, `datetime`

## 💻 How to Run

1. Make sure **Python 3** is installed on your Windows PC.
2. Download `Siber Koruyucu PRO.pyw` from this repository.
3. Double-click `Siber Koruyucu PRO.pyw` to launch the application directly with no background terminal window.
