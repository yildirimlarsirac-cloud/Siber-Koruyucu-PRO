# 🛡️ Siber Koruyucu PRO - AI & Cyber Defense Center

**Siber Koruyucu PRO** is a modern, lightweight desktop cybersecurity and AI-powered threat detection application built with Python and Tkinter. Designed to work **100% offline** with built-in **6-language support**, it protects users against common digital threats in a single clean interface.

## 🚀 Key Features

- **🔑 Password Shield:** Analyzes password strength against common patterns and generates cryptographically strong 16-character passwords.
- **🌐 Phishing Link Radar:** Scans URLs to detect phishing traps, raw IP addresses, `@` redirection tricks, and suspicious keywords.
- **🕵️ AI Scam SMS & Email Detector:** Uses offline NLP keyword analysis to calculate scam probability percentages in suspicious messages.
- **🔒 Crypto Vault (Encryption):** Locks sensitive notes or passwords using XOR + Base64 encryption protected by a secret PIN.
- **📡 Automatic Network Shield:** Automatically distinguishes between Wi-Fi and wired (Ethernet) connections upon opening the tab, auditing Wi-Fi encryption security and local IP status.
- **📋 Automated Security Logs:** Records every scan and analysis with timestamps into a local report (`siber_rapor.txt`).
- **⚙️ Settings & Multi-Language Support:** Instant switching between **Türkçe, English, Deutsch, Español, العربية, and Русский**.

## 🛠️ Technologies Used

- **Language:** Python 3
- **GUI Framework:** Tkinter (`ttk`)
- **Built-in Modules:** `re`, `socket`, `subprocess`, `random`, `base64`, `webbrowser`, `datetime`

## 💻 How to Run

1. Make sure **Python 3** is installed on your Windows PC.
2. Download `Siber Koruyucu PRO.pyw` from this repository.
3. Double-click `Siber Koruyucu PRO.pyw` to launch the application directly with no background terminal window.
